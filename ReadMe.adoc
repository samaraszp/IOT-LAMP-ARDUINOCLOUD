= Project: Lâmpada Inteligente IoT

Sistema de automação residencial e monitoramento ambiental utilizando o microcontrolador ESP32-S3 e integração com a plataforma Arduino IoT Cloud. O dispositivo monitora temperatura e luminosidade para controle autônomo local e permite operação remota em tempo real.

== Step 1: Installation

1. Acesse o ambiente do Arduino IoT Cloud.
2. Crie um novo "Thing" associado ao seu dispositivo ESP32-S3.
3. Adicione as propriedades correspondentes às variáveis do projeto (`led_color`, `lux_level`, `temperature` e `led_status`).
4. Insira as credenciais da sua rede Wi-Fi e a Secret Key gerada pelo sistema.
5. Copie os códigos do firmware deste repositório para a aba Sketch.

== Step 2: Assemble the circuit

Monte o circuito em uma protoboard utilizando os pinos GPIO dedicados do ESP32-S3 conforme a pinagem abaixo:

* *Sensor de Temperatura:* Conectado ao pino GPIO 4.
* *Sensor de Luz (LDR):* Conectado ao pino GPIO 5 com um resistor de 10k Ohm em configuração pull-down.
* *Potenciômetro:* Conectado ao pino GPIO 6.
* *Botão de Emergência:* Conectado ao pino GPIO 7 com interrupção externa.
* *LED RGB:* Canal Vermelho no GPIO 15, Verde no GPIO 16 e Azul no GPIO 17 (todos com resistores de 220 Ohm).
* *Buzzer:* Conectado ao pino GPIO 18.

== Step 3: Load the code

1. Conecte o ESP32-S3 ao computador via cabo USB.
2. Certifique-se de que o Arduino Create Agent esteja ativo em sua máquina.
3. Clique no botão de Upload na interface web para compilar e gravar o código na placa física.
